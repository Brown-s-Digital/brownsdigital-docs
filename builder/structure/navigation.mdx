Site chrome in the visual builder is the **Navigation** (header) block and the **Footer** block. They sit on every page through shared header/footer, not as one-off page content.

## Header

Add or select the Navigation block. Edit:

- **Brand name** — text in the header
- **Links** — one per line as `Label|/slug/` for an internal page, or `Label|https://…` for an external URL
- **Button label** and **Button link** — optional CTA in the header

Links open the path or URL you set. Internal paths should match a page slug on the site (for example `/contact/`).

## Footer

The Footer block uses the same link format (`Label|/slug/` per line), plus brand text and small print. Keep privacy and terms links accurate for your site.

## Announcement bar

The sticky announcement block is optional site-wide chrome above the header. It is a short message plus link, not a full menu.

## Preview

Change labels and destinations in the builder, save, then [preview on staging](/studio/publishing) before you promote. Broken links show up there the same way visitors will see them.
