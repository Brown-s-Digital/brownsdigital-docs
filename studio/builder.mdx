Open a site in Studio and edit pages on the canvas.

1. From **Sites** or the console, open the site you want to edit.
2. Use the builder to add and arrange pages and blocks. Save as you go.
3. In Simple mode the chrome stays quieter; full mode shows more tools. Either mode writes the same site.
4. Custom CSS is available on Build and higher plans.

Deeper block topics live under Builder — for example [API action](/builder/conversion/api-action). Structure docs are still thin; start here when you need the day-to-day canvas flow.

First site walkthrough: [Create a Site](/welcome/create-a-site). Publishing: [Preview and publish](/studio/publishing).
