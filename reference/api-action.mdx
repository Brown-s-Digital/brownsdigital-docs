The API action block sends a GET or POST request when a visitor taps the button. GET and POST are two common ways a browser asks another service to do something or return data.

The request runs in that visitor's browser, not on Browns Digital servers.

## What you need to know

- The URL must start with `https`.
- Studio does not limit which host you can enter, so the button can call any public HTTPS address.
- The request does not include the visitor's cookies. Cookie and Authorization headers are dropped.

Use a public webhook or gateway. A webhook is an address that another service gives you so it can receive a simple request. Do not point the block at an address that trusts the visitor's cookies, or that ignores where the request came from. A broad URL can make visitors call an address they did not choose.
