This page is a short path through Studio. Each step is one action.

Open Studio at [https://studio.brownsdigital.org/](https://studio.brownsdigital.org/).

## 1. Open Studio and sign in

1. Go to [https://studio.brownsdigital.org/](https://studio.brownsdigital.org/).
2. Wait until the sign-in screen says "Welcome back".
3. Choose one sign-in option:
   - Continue with passkey
   - the Google button
   - the GitHub button
   - or scan the code with your phone

Studio sign-in does not use a password. There is no email sign-up.

The account page is [https://brownsdigital.org/auth](https://brownsdigital.org/auth).

## 2. Finish the first-time setup

The first time you sign in, Studio starts onboarding.

1. On "Welcome to Studio", start onboarding.
2. Finish the policies step if Studio shows it. The details are on [Account onboarding](/get-started/account-onboarding).
3. Set your display name and a username, then choose **Next**.
4. Choose **Create a site**.

[Account onboarding](/get-started/account-onboarding) explains each of those screens in more detail.


## 3. Create your first site

1. Choose a template.
2. Enter a site name.
3. Optionally add a logo and a short description.
4. If Studio shows Look & feel, pick an icon, a colour, a page background, and a button shape, then choose **Create site**. You can also skip that step and go to the canvas.

Studio then opens the visual builder for that site.

## 4. Use the publish screens when you are ready

Console shows **Create preview** (or **Update preview**) and **Push to live** (or **Update live**). The Publish dialog is where you set a site address if Studio asks for one. [Publish a site](/get-started/publish-a-site) describes those screens. It does not confirm that a preview or a live site is created today.

The screens say that preview and live share the same site address, and that you cannot change that address after the first publish.

## If something goes wrong

- If the screen says "Studio is paused", Studio is in maintenance or a planned downtime window. Wait and try again shortly.
- If sign-in does not continue, try another sign-in option on the same screen, or ask for help at [info@brownsdigital.org](mailto:info@brownsdigital.org).
- If Studio will not create the site, it may already have as many sites as your account allows. The message you see will say so.
