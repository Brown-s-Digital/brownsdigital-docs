You can create a site at the end of onboarding, or later from Studio. In both cases you pick a template, give the site a name, and open the visual builder.

*Last checked: 20 November 2026.*

## Start from onboarding

After you save your profile, Studio shows **Next, create a site**.

1. Choose **Create a site**.
2. On the next welcome screen, choose **Create my site**.

## Start from Studio

If you already have an account:

1. Open Studio and sign in.
2. Open **Sites** in the sidebar.
3. Choose **New site**.

You can also search Studio and run **New site**. On a Mac, the search shortcut is Command K. On other computers it is Ctrl K.

If your account cannot hold another site, Studio does not show the create controls and explains the limit.

## 1. Choose a template

The sheet is titled **Choose a template** and is labelled **Step 1 of 3** for site setup (or **New site · Step 1 of 3** if you started from Sites).

1. Browse the templates. You can search if a search box is shown.
2. Select one template. You must pick a template before you can continue.
3. Choose **Continue**.

## 2. Name the site

1. Enter a **Site name** (required, up to 120 characters).
2. Optionally upload a **Site logo**.
3. Optionally add a **Short description** (up to 320 characters).
4. Choose **Continue**. In Simple mode this button says **Create my site** and skips the next step.

## 3. Look & feel

This step is skipped in Simple mode.

1. Optionally pick a site icon. This is the small icon beside the site name in Studio.
2. Choose a tone, a main colour, a page background, a button shape, text size, fonts, and how rounded corners should feel.
3. Choose **Create site**.

You can also choose **Skip to canvas**. Studio still needs a template and a site name first. The site then uses the template's colours, type, and corners.

## What you should see

Studio creates the site and opens the visual builder. The builder has three parts: pages on the left, the canvas in the middle, and an inspector on the right.

Creating a site does not put it on the public web yet. The preview and live screens are described in [Publish a site](/get-started/publish-a-site).

## If something goes wrong

- If you have not picked a template, Studio says: "Pick a template first."
- If the site name is empty, Studio says: "Enter a site name to continue."
- If two sites would share the same address, Studio asks you to rename one or choose a different address.
- If templates do not load, Studio says it could not load templates. Try again, or check [system status](https://status.brownsdigital.org/).
- If your account is at its site limit, Studio explains this and does not create the site.
